# Petrol Pump Manager

Responsive web app starter for phone + laptop.

## Run on Mac / Windows
1. Install Python 3.11+.
2. Open Terminal in this folder.
3. Create a virtual environment:
   `python3 -m venv .venv`
4. Activate:
   `source .venv/bin/activate` (Mac/Linux)
   `.venv\Scripts\activate` (Windows)
5. Install:
   `pip install -r requirements.txt`
6. Start:
   `python app.py`
7. Open `http://127.0.0.1:5000`

Initial admin:
- Username: admin
- Password: admin123

IMPORTANT:
This is a working starter. Before real production use, change the secret/passwords and move to a hosted MySQL/PostgreSQL database with HTTPS, backups, stronger validation, and proper deployment.
